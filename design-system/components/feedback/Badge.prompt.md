The small status vocabulary: file-type badge, context chip, error count, keycap.

```jsx
<Badge type="js" />  <Badge type="html" />
<Chip tone="ok">SP: Live</Chip>  <Chip tone="warn">SP: Mock</Chip>
<CountPill>3</CountPill>
<Kbd>Ctrl/Cmd + Enter</Kbd>
```

One context chip per tool. `Ctrl/Cmd + Enter` always runs; `Esc` always steps back one level.
